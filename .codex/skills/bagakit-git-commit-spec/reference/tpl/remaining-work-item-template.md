# Remaining Work Item Template

Use this template under `## Remaining Work` in commit messages.

## No Remaining Work

```markdown
## Remaining Work
- None
```

## With Remaining Work

```markdown
## Remaining Work
- What: <one sentence describing what remains>
- Why Pending: <one sentence describing why it is not completed in this commit>
- Plan: <one sentence describing how/when it will be completed>
```

Repeat the 3-line block for each remaining item.
