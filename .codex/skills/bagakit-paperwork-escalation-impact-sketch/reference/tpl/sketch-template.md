# EIS Sketch Template

- Hook: 谁把复盘会链接发到客户群了？
- PingPong-1（冲突角色A）: 我问你谁来发通知，你说你已经发了。
- PingPong-2（冲突角色B）: 我问你发哪个群，你说“就那个有老板的”。
- PingPong-3（冲突角色A）: 我问你老板在不在，你说他今晚不看消息。
- Escalation: 现在会议室投屏上是测试版事故看板，客户和候选人都在第一排。
- Anchor Question（压场角色）: 老板现在看到哪一页？
- Mid Answer（冲突角色A/B）: 看到“回滚失败”和“责任人待定”那一页。
- Cold Knife（门口角色）: 老板回了："这页是我刚翻到的，我和客户坐第一排。"
