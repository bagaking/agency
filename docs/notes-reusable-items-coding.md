## Governed Source Policy
- Repo-authored source in governed roots (`apps/`, `pkg/`, `scripts/`) is TypeScript-only.
- Generated output (`dist/`, `.electron-build/`) and vendored dependencies are excluded from this rule.
- Validator entrypoint: `sh scripts/check_no_governed_js.sh .`

## Deprecations
- `App.tsx` inline layout wiring blocks (editor pane + panel props + `AppLayout` props) are deprecated in favor of `buildComposedAppLayoutProps` as the single composition seam (`apps/editor/renderer/src/app/buildComposedAppLayoutProps.ts`).
- Legacy local `showCreate` modal-state wiring in `App.tsx` is deprecated; use `useCreateCellModalLauncher` + modal system launch flow (`apps/editor/renderer/src/app/useCreateCellModalLauncher.tsx`, `apps/editor/renderer/src/app/useCellLifecycleActions.ts`).
